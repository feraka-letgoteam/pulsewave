# PULSEWAVE

Analog-modeling synthesizer workstation. Dual VCOs, sub, noise, dual 24 dB filters, dual ADSR, LFO bank, 8-slot mod matrix, 16-step sequencer, arpeggiator, tape deck, sample pad, and a CRT chassis.

Play from the on-screen keys, the computer keyboard (Z/Q rows, `[` `]` octave), or MIDI. Factory bank is 32 patches. WRITE stores programs in the browser; EXPORT dumps JSON.

## Run

```bash
npm install
npm run dev
```

Click a key after boot. PLAY runs the sequencer. Drop a WAV/MP3 onto the panel to map it chromatically.
